A small program that writes exactly one word (11 characters) to `/output/entry.txt`: the first word that comes to mind — "hornswoggle". No topic, no explanation, no second draft: a verb meaning to cheat or bamboozle, surprising, vivid, and witty in a single word.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
